# Security policy

Report a vulnerability in the fixture validator or repository workflows to
**security@inkwell.software**.

Include the affected version or commit, the steps to reproduce the problem,
and its impact. Use a small fictional input for the reproduction. Send security
details by email so maintainers can investigate and coordinate a fix.

For a fixture correction or an import difference, open an
[interop issue](https://github.com/inkwell-app/screenplay-interop/issues/new?template=interop.yml).
