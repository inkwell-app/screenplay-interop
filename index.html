What survives a screenplay file transfer?

A ten-minute lab for screenwriting students. A transfer can preserve every word and still change what the actors do. Use these two short examples to check timing and production numbering.

1. Listen for the overlap

INT. SWITCH ROOM - NIGHT

MIRA
Keep the north line open.

TOMAS ^
The south line is already ringing.

Read this twice with a partner. First take turns. Then have Tomas start while Mira is still speaking. Which reading does the writer specify?

Check your reading

The caret after TOMAS marks dual dialogue in Fountain. Both actors speak at the same time. In a formatted script, look for paired dialogue columns. A conversion that stacks the lines as ordinary turns loses a timing instruction.

2. Follow the scene numbers

A production draft labels the weather station scene 7 and the observatory steps 7A. The crew has already labeled its notes with those numbers. Predict what happens to those notes if a new editor automatically numbers the scenes 1 and 2.

Check the handoff

These two headings carry the original scene numbers in the FDX file.

<SceneProperties Number="7"/><Text>INT. WEATHER STATION - DAWN</Text>
<SceneProperties Number="7A"/><Text>EXT. OBSERVATORY STEPS - DAY</Text>

Renumbering the headings breaks the link to the crew’s notes. Check both labels before circulating the new draft.

Try it in your editor

Download the Fountain scene and FDX scene. Import a file your editor supports, export it in the same format if available, and reopen it. Record the editor version, what you saw after import, and what survived reopening. If export is unavailable, record that limit.

For discussion: Which change would a reader notice at a table read? Which would a script supervisor need to catch before the shoot?
